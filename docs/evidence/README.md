# Evidence

Screenshots, recordings and measured output backing each spike's go/no-go in
`docs/SPIKES.md`. An outcome without an artefact here is not an outcome.

Naming: `spike<N>-<slug>.<ext>` — e.g. `spike2-layout.png`.

Keep files small (screenshots, not video where a frame sequence will do). Every
image must be reproducible by a documented command in `docs/SPIKES.md` or the
story that produced it.
